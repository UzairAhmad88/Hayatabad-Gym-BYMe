# HAYATABAD GYM Design System

## Colors
- Background: #080808
- Surface: #121212
- Surface 2: #1B1B1B
- Accent: #B7FF00
- Foreground: #FFFFFF
- Muted: #A5A5A5

## UI
Use rounded cards sparingly. Prefer large typography, whitespace, photography, and strong CTAs.

## Motion
Use short, purposeful transitions. Respect `prefers-reduced-motion`.

## Components
Navbar, Footer, Button, ProgramCard, TrainerCard, MembershipCard, GalleryCard, Forms, CTA, SectionHeading.
