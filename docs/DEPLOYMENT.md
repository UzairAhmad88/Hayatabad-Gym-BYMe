# Deployment Checklist

1. Create GitHub repository.
2. Configure production database.
3. Add environment variables to hosting.
4. Run Prisma migrations.
5. Deploy Next.js application.
6. Configure custom domain.
7. Verify HTTPS.
8. Test all forms.
9. Test WhatsApp, phone and map actions.
10. Test SEO metadata and sitemap.
11. Run Lighthouse/performance checks.
12. Verify admin authentication.
13. Confirm backups and database access policy.
